# Guía de contribución — ShelfWise

Gracias por contribuir a este ejercicio de buenas prácticas.

## Flujo

1. Fork o branch desde `main`
2. Crea `feature/...` o `fix/...`
3. Commits con Conventional Commits
4. Abre un Pull Request usando la plantilla
5. Espera CI verde + review

## Estándares

- Código en `src/`, tests en `tests/`, docs en `docs/`
- No subir `.env` ni secretos
- `npm run test:all` debe pasar antes del PR
- PRs pequeños y con descripción clara

## Reportar bugs

Usa el template de Issue **Bug report** y agrega pasos para reproducir.
